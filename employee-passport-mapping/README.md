# Employee Passport Mapping

## Overview
This project demonstrates Hibernate One-to-One Mapping between Employee and Passport entities. It performs CRUD operations while implementing cascading, fetch strategies, and validation.

## Technologies Used
- Java 17
- Spring Boot
- Hibernate ORM
- MySQL
- Maven
- Lombok
- Postman

## Features
- Create Employee
- Assign Passport
- Retrieve Employee with Passport
- Delete Employee
- One-to-One Mapping
- Cascade Operations
- Lazy/Eager Fetch
- Validation
- Exception Handling

MySQL
