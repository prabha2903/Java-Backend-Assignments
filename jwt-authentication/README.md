# JWT Authentication System

## Overview
This project provides secure authentication and authorization using Spring Security and JWT. Users can register, log in, generate JWT tokens, and access protected APIs.

## Technologies Used
- Java 17
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok
- Postman

## Features
- User Registration
- User Login
- JWT Token Generation
- Secure REST APIs
- Password Encryption using BCrypt
- Profile Update
- Validation
- Global Exception Handling

MySQL
