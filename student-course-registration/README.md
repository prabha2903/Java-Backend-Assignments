# Student Course Registration System

## Overview
This project demonstrates Hibernate Many-to-Many Mapping between Student and Course entities. It allows students to enroll in courses and manage enrollments efficiently.

## Technologies Used
- Java 17
- Spring Boot
- Hibernate ORM
- MySQL
- Maven
- Lombok
- Postman

## Features
- Register Student
- Create Course
- Enroll Student
- Remove Enrollment
- View Student Courses
- View Course Students
- Many-to-Many Mapping
- Validation
- Exception Handling

## Database
MySQL
