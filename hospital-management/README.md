# Hospital Management System

## Overview
This project is developed using Hibernate to manage doctors, patients, and appointments. It demonstrates entity relationships, cascading, validations, and exception handling.

## Technologies Used
- Java 17
- Spring Boot
- Hibernate ORM
- MySQL
- Maven
- Lombok
- Postman

## Features
- Add Doctor
- Add Patient
- Schedule Appointment
- View Appointments
- Delete Appointment
- One-to-Many Mapping
- Many-to-One Mapping
- Validation
- Exception Handling

MySQL
