# Java Backend Assignments

## Overview

This repository contains the projects developed as part of the **Java Backend Developer Assessment**. The projects are implemented using **Spring Boot**, **Hibernate**, **MySQL**, and **Java 17**, following industry-standard coding practices, layered architecture, RESTful API design, validation, and exception handling.

## Repository Structure

```
Java-Backend-Assignments
│
├── Student-Management-System
├── Product-Inventory-Management
├── JWT-Authentication-System

├── Hospital-Database-Management
└── Student-Course-Registration
```
