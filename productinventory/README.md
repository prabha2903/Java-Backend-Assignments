# Product Inventory Management System

## Overview
This project is a RESTful API developed using Spring Boot to manage warehouse products. It supports product management, searching, pagination, sorting, validation, and exception handling.

## Technologies Used
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok
- Postman

## Features
- Add Product
- Update Product
- Delete Product
- Search by Category
- Search by Price Range
- Low Stock Products
- Pagination
- Sorting by Price
- Sorting by Product Name
- Validation
- Global Exception Handling

MySQL
